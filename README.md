# dayily-site

> Health isn’t built in a day. It’s built Dayily

[![Play Store](https://img.shields.io/badge/Google_Play-414141?style=flat&logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=com.dayily)

Static public website for Dayily, intended for GitHub Pages.

## Structure

- `/` — English version;
- `/ru/`, `/es/`, `/pt/`, `/fr/`, `/zh/` — localized versions;
- `/privacy/` and the corresponding language paths — Privacy Policy;
- `assets/` — local CSS, the Dayily mark, and the Onest font.

The site uses no bundler, framework, external fonts, trackers, or backend.
All links are designed for GitHub Project Pages.

- **Website:** [Dayily website](https://preeternal.github.io/dayily-site/)
- **Android app:** [Get Dayily on Google Play](https://play.google.com/store/apps/details?id=com.dayily)
