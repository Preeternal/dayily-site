Dayily

Supprimer votre compte Dayily

Cette page explique comment supprimer définitivement votre compte Dayily et les données Dayily qui lui sont associées.

Supprimer votre compte dans l’application

Vous pouvez supprimer définitivement votre compte Dayily directement dans l’application Dayily :

Réglages → Compte cloud → Supprimer le compte et les données

Cette action supprime définitivement votre compte Dayily, les entraînements locaux de ce profil et les données cloud associées.

Si vous n’avez pas accès à l’application

Envoyez une demande de suppression du compte à dayily.review@gmail.com depuis l’adresse email associée à votre compte Dayily. Indiquez suffisamment d’informations pour identifier le compte.

Données gérées par d’autres services

Cette demande ne supprime pas les données stockées indépendamment dans Apple Health, Health Connect, Google Play ou l’App Store. Ces données et comptes doivent être gérés dans le service concerné.

Supprimer des données sans supprimer le compte

Dayily ne propose actuellement pas de demande séparée pour supprimer une partie ou la totalité des données serveur tout en conservant le compte Dayily. Vous pouvez supprimer des entraînements individuels dans l’application, mais la suppression complète du compte et des données cloud associées fait partie de la suppression du compte.
